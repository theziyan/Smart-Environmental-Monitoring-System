# Smart-Environmental-Monitoring-System
A zero-cost virtual environmental monitoring system using Arduino Uno Rev3 and a DHT22 sensor, with temperature and humidity alerts.
## 🚀 Live Simulation

Run and explore the virtual Arduino circuit on Wokwi:

**[Open the Smart Environmental Monitoring System Simulation]([PASTE_YOUR_WOKWI_LINK_HERE](https://wokwi.com/projects/478027912610424833))**

The simulation uses an Arduino Uno Rev3 and DHT22 sensor to monitor temperature and humidity and trigger alerts when thresholds are reached.
